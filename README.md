# Thème Audace Magazine

Thème WordPress sur mesure pour [audacemagazine.com](https://www.audacemagazine.com),
destiné à remplacer Extra : un thème de magazine professionnel, avec le
magazine en ligne (kiosque) au centre.

État : projet créé le 18 novembre 2026, rien d'écrit. Le contexte, les
règles et la prochaine étape sont dans `CLAUDE.md`.
